# Ishtiyaq Gulzar — Full-Stack Web Designer Portfolio

Personal editorial portfolio website for **Ishtiyaq Gulzar** (`Eshu927` / *Bhat ishtiyaq #webdesigner*), a full-stack web designer based in **Shopian, Jammu & Kashmir**.

🌐 **Live Site:** [https://eshu927.github.io](https://jaani927.netlify.app)

---

## ✨ Key Features

- **Editorial Dark UI:** High-contrast `#0a0a0c` theme paired with *Syne*, *Playfair Display*, and *Inter* typography.
- **3-Video Scroll Choreography:** Smooth, scroll-synchronized background video stage with radial vignette masking.
- **Filterable Project Showcase (15+ Projects):** Categorized across *Business Sites*, *Wedding Invites*, and *Special Occasions*, complete with interactive detail modals.
- **Live Client Feedback Wall:** Real-time review submission, star ratings, compressed client photo uploads, likes, nested replies, and PIN-protected admin moderation powered by **Firebase Realtime Database**.
- **Direct WhatsApp Integration:** Instant project inquiry and service booking links.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+), Canvas & Keyframe Animations
- **Backend & Database:** Firebase Realtime Database, Python, Flask, SQLite3
- **Hosting & Domains:** GitHub Pages, GoDaddy DNS
